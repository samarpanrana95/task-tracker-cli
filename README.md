# task-tracker-cli
A simple command line interface to track what I need to do, what I have done and what I'm currently working on.

Runs from the Command line and accepts user actions and inputs as arguments, then stores the tasks in a json file. 

User can:

Add, update and delete tasks
Mark a task as in progress or done
List all the tasks
List all the tasks that are done / not done / in progress 

Run the program through npm run task-cli
